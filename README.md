# Tic-Tac-Toe Game 🎮<br>
A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. It provides an engaging way to play the classic game in a browser.<br>

Features ✨<br>
✅ Two-Player Mode for an exciting challenge.<br>
✅ Dynamic UI Updates with real-time game status.<br>
✅ Win Detection Logic to highlight the winner.<br>
✅ Reset Button to start a new game anytime.<br>
✅ Responsive Design for smooth gameplay on desktop 💻 and mobile 📱.<br>

This project is perfect for learning DOM manipulation, improving JavaScript logic, and building interactive web applications. 🚀
